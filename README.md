# Nikhil Srivastava
### Business Strategy · Transformation · AI-Enabled Systems

I work at the intersection of **business strategy, operating-model design, venture building, and technology-enabled execution**. My focus is turning complex business problems into practical, decision-ready systems: clear choices, validated assumptions, measurable outcomes, and an actionable path to implementation.

## Featured work — B-PAL (Business PAL)

**A live business advisory and venture-architecture platform.**

[**Explore the live B-PAL website →**](https://b-pal.vercel.app/)

B-PAL brings together connected advisory systems, practical frameworks, and selected casework to illustrate how strategy can be translated into evidence, decisions, operating models, and execution.

**What the project demonstrates**
- **Business architecture:** advisory frameworks, venture development, business design, and transformation thinking.
- **Strategy to execution:** evidence-led diagnostics, decision gates, governance, operating models, and measurable progress.
- **Digital implementation:** a responsive, production-deployed website with structured content and casework presentation.
- **Technology stack:** React, TypeScript, TanStack Start / Router, Vite, Tailwind CSS, and Vercel, with Vercel Analytics integrated.

**Project status:** Live on Vercel · Actively maintained · **Source repository is private**.

> The B-PAL application's source code is intentionally kept in a private GitHub repository. The public website is available for review; this profile documents the work without exposing the underlying repository or its source files.
